## ☕ Brew Heaven Power BI Dashboard

### 📖 Overview
An interactive Power BI dashboard for **Brew Heaven**, a local coffee shop chain, bringing together sales, inventory and customer feedback data.
The dashboard gives insights into:
- Sales trends and product performance
- Customer satisfaction and feedback
- Stock levels and reorder management

### 🧰 Features
- Two interactive report pages: **Sales Page** and **Management Page**
- Sales visualized **by category, time and product**
- **Customer feedback** integrated, with **average ratings** calculated
- **Power Query** used for data transformation and cleaning

### 💡 Skills Demonstrated
Power BI · Data Cleaning & Modeling · Data Visualization · DAX Calculations · Business Insights & Reporting

## 🧾 Client Brief to Delivery: Fee Receipts Cleaning (Excel)

### 📖 Overview
A practice order done like a real freelance job: a (made-up) tuition centre sends messy fee receipts and 9 requests. Cleaned with formulas only (names, cities, phones, text fees), repeated receipts removed by **Receipt No** (three different students share one name, so name-based de-duplication would be wrong), and a Checks sheet proves nothing was lost: 35 rows → 30 clean, fees 59,700 → 54,000, plus fees per city.
*All data is made up, for demonstration only.*

### 💡 Skills Demonstrated
Reading a client brief · TRIM · PROPER · SUBSTITUTE · VALUE · XLOOKUP · COUNTIF · FILTER · SUMIFS · Data reconciliation

### 🖼️ Project Preview
![Fee Receipts Checks](./Fee-Receipts-Cleaning/Checks.png)
